## Описание задачи

Бинарная классификация пациентов по риску сердечно-сосудистого заболевания на основе клинических показателей: возраст, пол, давление, холестерин, индекс массы тела, курение, диабет, физическая активность и др. Сравнение моделей: логистическая регрессия, случайный лес, градиентный бустинг. Метрики: accuracy, precision, recall, F1, ROC-AUC.

**Задача:** Классификация

**Датасет:** Indicators of Heart Disease - https://www.kaggle.com/datasets/kamilpytlak/personal-key-indicators-of-heart-disease?resource=download

**Целевая метрика:** ROC-AUC
